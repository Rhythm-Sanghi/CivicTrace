# Security Policy

## Supported Versions
| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |

## Reporting a Vulnerability
If you discover a security vulnerability or potential tamper flaw within CivicTrace (including cryptographic hash chaining bypasses or role privilege escalation):
- Please report vulnerabilities responsibly to security@civictrace.local or create a private security advisory on GitHub.
- Do not disclose issues publicly until a patch is released.
